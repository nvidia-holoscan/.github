# NVIDIA Holoscan

Build real-time AI applications from live sensor data. [NVIDIA Holoscan](https://developer.nvidia.com/holoscan-sdk) brings together low-latency sensor and network I/O, accelerated data processing, and AI—from embedded systems to edge to cloud.

**New to Holoscan?** [Explore the Holoscan developer site](https://nvidia-holoscan.github.io/) · [Get started with the SDK](https://docs.nvidia.com/holoscan/sdk-user-guide/introduction/getting-started) · [Browse the SDK source](https://github.com/nvidia-holoscan/holoscan-sdk)

## Build with Holoscan

- [**Holoscan SDK**](https://github.com/nvidia-holoscan/holoscan-sdk) — build streaming and imaging pipelines. [Installation options](https://docs.nvidia.com/holoscan/sdk-user-guide/setup/sdk-installation) · [User guide](https://docs.nvidia.com/holoscan/sdk-user-guide/).
- [**HoloHub**](https://github.com/nvidia-holoscan/holohub) — community-driven gateway to reference applications, tutorials, and reusable module projects.
- [**Holoscan Sensor Bridge**](https://github.com/nvidia-holoscan/holoscan-sensor-bridge) — connect custom sensors to Holoscan applications over Ethernet. [Documentation](https://docs.nvidia.com/holoscan/sensor-bridge/latest).
- [**Networking with DAQIRI**](https://github.com/NVIDIA/daqiri) — ingest and transmit high-rate sensor data over low-latency network connections in Holoscan applications. [DAQIRI + Holoscan guide](https://nvidia.github.io/daqiri/tutorials/daqiri-holoscan-integration/).
- **Deployment stack** — build customized Linux images for NVIDIA IGX with OpenEmbedded/Yocto. [Deployment guide](https://docs.nvidia.com/holoscan/sdk-user-guide/setup/additional-setup/deployment-stack).
